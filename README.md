A desktop application developed using Visual Basic .NET, Windows Forms, and Microsoft SQL Server to manage library operations and database records.

🛠️ Technologies Used
Visual Basic .NET (VB.NET)
.NET 6.0
Windows Forms
Microsoft SQL Server
ADO.NET
SQL
✨ Features
Book Management: Add, update, delete, search, and display book records.
Member Management: Manage library member information.
Loan Management: Record and manage book loans.
Database Integration: Connect the application to Microsoft SQL Server.
Data Display: Display database records using DataGridView.
SQL Queries: Retrieve related information using JOIN operations.
🗄️ Database Structure
The application uses a relational database with three main tables:

Table

Description

Books

Stores book information

Members

Stores library member information

Loans

Stores book loan records

Primary Keys and Foreign Keys are used to establish relationships between the tables.

🚀 Getting Started
Prerequisites
Visual Studio 2022
.NET 6.0 SDK
Microsoft SQL Server
SQL Server Management Studio (SSMS)
Installation
Clone this repository:
git clone https://github.com/ikram134/Library_Management_System.git
Open the solution file in Visual Studio.
Create the database in Microsoft SQL Server.
Execute the provided SQL script to create the tables and insert sample data.
Update the connection string according to your local SQL Server instance.
Build and run the application.
